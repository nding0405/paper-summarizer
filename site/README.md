# site/

The browser interface now lives in the Java/JSP application under
`src/main/webapp/` and is served by Tomcat (`make serve`). The static
`index.html`, `app.js`, and `styles.css` client that used to live here was
retired in September 2026.

This directory only holds data consumed at build time:

- `data/fixture-papers.json` — committed synthetic fixture; the packaged
  fallback when no generated export exists.
- `data/papers.json` — generated by `make export`; never hand-edited.
- `data/venue-years.json` — generated coverage manifest; never hand-edited.

The WAR build copies these files into `WEB-INF/data/`.
